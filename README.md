## Device and iOS Version
Currently we are only supporting iPod Touch 1st Gen and 2nd Gen.
- iPod Touch 1st Gen have iPhoneOS 1.0 in emulator.
- iPod Touch 2nd Gen have iPhoneOS 2.0 in emulator..
